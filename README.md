to play, just download all files and open the html file in chrome.
if there are any bugs, please let me know on Stardance

Features:
Timing minigame, you have to press space when the indicator is orange to get points

Blocking minigame: inspired by Undertale's Undyne fight, you have to block incoming arrows with a shield

Hot potato minigame: you have to keep the indicator constantly moving, and you can get points for waiting until the last second.

Gate minigame: move the gate so that the arrows can get through
